## What This Control Means

User-chosen passwords must have a minimum length: at least 8 characters as the baseline, with 15 or more strongly recommended. Length is the single most important factor in password strength, so the floor must be enforced — never 6, 4, or none.

## Why This Matters

Length, not complexity, is what makes passwords resistant to guessing and cracking. Longer passphrases vastly increase the search space an attacker must traverse, while short passwords fall to brute force regardless of how few digits they contain. Enforcing a meaningful minimum is the cheapest, highest-impact password control available.

## Main Security Requirement

> Verify that user set passwords are at least 8 characters in length although a minimum of 15 characters is strongly recommended.

In practice this means rejecting shorter values at set/reset time.

## Common Failure Patterns

- **Low minimums** — 4 or 6 character floors inherited from legacy policy.
- **Silent truncation** — longer passwords cut before storage, negating length.
- **No server-side check** — length enforced only in the browser.
- **Inconsistent floors** — reset flow allows what registration forbids.

## Secure Implementation

Enforce length on the server, counting characters (not bytes) and allowing long passphrases:

```javascript
const MIN_LENGTH = 8;      // absolute minimum
const PREFERRED = 15;      // encourage passphrases

function validatePassword(password) {
  if (typeof password !== "string" || Array.from(password).length < MIN_LENGTH) {
    throw new Error(`Password must be at least ${MIN_LENGTH} characters`);
  }
}
```

## Key Rules

- Require at least 8 characters; recommend and encourage 15+.
- Enforce the minimum on the server, not just the client.
- Count characters, not bytes, to handle Unicode passphrases.
- Never truncate; verify the full password exactly as entered.
- Apply the same minimum across registration, change, and reset.

## Checklist for Code Review

- Is there a minimum password length of at least 8 characters?
- Is the check enforced server-side?
- Are longer passwords accepted without truncation?
- Is the same minimum applied on every password path?
- Does the UI encourage passphrases of 15+ characters?
