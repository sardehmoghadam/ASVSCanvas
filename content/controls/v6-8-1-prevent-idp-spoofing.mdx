## Requirement

Verify that, if the application supports multiple identity providers (IdPs), the user identity cannot be spoofed via another supported identity provider (e.g., by using the same user identifier). The standard mitigation would be for the application to register and identify the user using a combination of the IdP ID (serving as a namespace) and the user ID in the IdP.
