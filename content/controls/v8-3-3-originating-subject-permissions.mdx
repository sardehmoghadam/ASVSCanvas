## Requirement

Verify that access to an object is based on the originating subject (e.g., consumer) permissions, not on the permissions of any intermediary or service acting on their behalf. For example, if a consumer calls a web service using a self-contained token for authentication, and the service then requests data from a different service, the second service will use the consumer token, rather than a machine-to-machine token from the first service, to make permission decisions.
