## What This Control Means

If sessions are represented by reference tokens (opaque identifiers that map to server-side session records), those identifiers must be produced by a cryptographically secure pseudo-random number generator (CSPRNG) and carry at least 128 bits of entropy, so they cannot be guessed or brute-forced.

## Why This Matters

A reference token is the only secret standing between an attacker and the session it identifies. If it is generated by a predictable PRNG or is short, an attacker can enumerate or predict valid tokens and hijack arbitrary sessions. A CSPRNG with ≥128 bits of entropy makes the token space large and unpredictable enough to defeat guessing.

## Main Security Requirement

> Verify that if reference tokens are used to represent user sessions, they are unique and generated using a cryptographically secure pseudo-random number generator (CSPRNG) and possess at least 128 bits of entropy.

In practice this means CSPRNG-derived, unique, ≥128-bit opaque session identifiers.

## Common Failure Patterns

- **Weak RNG** — `Math.random()` or time-based generation.
- **Low entropy** — short or sequential token values.
- **Reused identifiers** — same token issued to multiple sessions.
- **Predictable structure** — user ID or counter embedded in the token.

## Secure Implementation

Generate reference tokens with a CSPRNG at 128+ bits:

```javascript
import { randomBytes } from "node:crypto";

function generateSessionToken() {
  return randomBytes(16).toString("base64url"); // 128 bits of entropy
}
```

## Key Rules

- Generate reference tokens with a CSPRNG.
- Ensure at least 128 bits of entropy per token.
- Keep tokens unique — never reuse an issued value.
- Use no predictable structure (IDs, timestamps, counters).
- Prefer ≥128 bits; more is fine, less is not.

## Checklist for Code Review

- Is a CSPRNG used (not `Math.random()`)?
- Do reference tokens have ≥128 bits of entropy?
- Are tokens guaranteed unique?
- Is any predictable structure embedded in tokens?
- Are tokens generated server-side only?
