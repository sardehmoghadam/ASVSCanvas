## What This Control Means

Documentation must identify the secrets critical to the application's security and define a rotation schedule for each, driven by the organization's threat model and business requirements.

## Why This Matters

Secrets that never rotate are secrets that eventually leak — and when one does, its exposure window is unbounded. Naming which secrets matter and how often to rotate them turns rotation from an ad-hoc chore into a planned, risk-based control, limiting the blast radius of any single compromise.

## Main Security Requirement

> Verify that the application documentation defines the secrets that are critical for the security of the application and a schedule for rotating them, based on the organization threat model and business requirements.

In practice this means a documented secret inventory with a rotation cadence.

## Common Failure Patterns

- **Critical secrets unnamed** — what matters is undefined.
- **No schedule** — rotation never planned.
- **Uniform cadence** — rotation ignores risk tiering.
- **Rotation disruptive** — no overlap/dual-auth approach.
- **Documentation stale** — new secrets not added.

## Secure Implementation

Maintain a secret inventory with risk-based rotation cadence:

```yaml
secrets:
  - name: oauth-signing-key
    criticality: high
    rotation: "30 days"
    overlap: true          # support old + new key during rotation
  - name: smtp-credentials
    criticality: medium
    rotation: "90 days"
  - name: feature-flag-token
    criticality: low
    rotation: "180 days"
```

## Key Rules

- Identify every security-critical secret.
- Assign a rotation schedule per secret.
- Base cadence on threat model and business impact.
- Allow overlap (dual keys) for graceful rotation.
- Keep the inventory current as secrets change.

## Checklist for Code Review

- Are all critical secrets documented?
- Does each secret have a rotation schedule?
- Is cadence tied to criticality and threat model?
- Is rotation non-disruptive (overlap supported)?
- Is the inventory kept up to date?
