## Requirement

Verify that adaptive security controls based on a consumer environmental and contextual attributes (such as time of day, location, IP address, or device) are implemented for authentication and authorization decisions, as defined in the application documentation. These controls must be applied when the consumer tries to start a new session and also during an existing session.
