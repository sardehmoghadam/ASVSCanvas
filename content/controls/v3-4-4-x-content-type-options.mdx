## Requirement

Verify that all HTTP responses contain an X-Content-Type-Options: nosniff header field. This instructs browsers not to use content sniffing and MIME type guessing for the given response, and to require the response Content-Type header field value to match the destination resource. For example, the response to a request for a style is only accepted if the response Content-Type is text/css. This also enables the use of the Cross-Origin Read Blocking (CORB) functionality by the browser.
